# Data Dictionary

## 1. List of Orders

| Column | Description | Data Type | Business Use |
|---|---|---|---|
| Order ID | Unique identifier for an order | Text | Links order information with order details |
| Order Date | Date on which the order was placed | Date | Time-based sales analysis |
| CustomerName | Name of the customer | Text | Out of scope for this project |
| State | State associated with the order | Text | Geographical analysis |
| City | City associated with the order | Text | City-level geographical analysis |

## 2. Order Details

| Column | Description | Data Type | Business Use |
|---|---|---|---|
| Order ID | Identifier associated with the order | Text | Links order details with order information |
| Amount | Sales/revenue generated by the order line | Numeric | Sales performance analysis |
| Profit | Profit or loss generated by the order line | Numeric | Profitability analysis |
| Quantity | Number of units sold | Numeric | Product performance analysis |
| Category | Main product category | Text | Category-level analysis |
| Sub-Category | Detailed product classification | Text | Sub-category analysis |

## 3. Sales Target

| Column | Description | Data Type | Business Use |
|---|---|---|---|
| Month of | Month associated with the sales target | Date/Month | Monthly target analysis |
| Category | Product category for which the target is defined | Text | Category-level target analysis |
| Target | Sales target amount | Numeric | Actual sales vs target comparison |

## Important Data Notes

- `Amount` represents sales/revenue in the Order Details dataset.
- `Order ID` can appear multiple times in Order Details because one order can contain multiple line items.
- `CustomerName` is available in the raw data but is outside the scope of this project.
- Negative values in `Profit` represent losses.
